# About Tydgenoot

**Tydgenoot** is a distraction-free, full-screen digital wall clock engineered specifically to breathe new life into older Android tablets mounted as permanent room fixtures. 

## Design Philosophy
- **Authentic Aesthetics:** Recreates the charm of classic hardware LED segment displays using lightweight vector drawing instructions rather than rigid bitmap font files.
- **Zero Clutter:** Excludes weather widgets, alarms, and unnecessary network services to focus purely on displaying time and date cleanly.
- **Hardware Longevity:** Incorporates automatic screen burn-in shifting to protect older display panels during 24/7 plugged-in operation.

## Built With
- Kotlin & Jetpack Compose
- AndroidX ViewModel & Jetpack DataStore
- Multiplatform Markdown Renderer
